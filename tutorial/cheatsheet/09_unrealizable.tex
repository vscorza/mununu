\begin{cheatbox}{Unrealizable}
A specification is \textbf{unrealizable} when \emph{no controller} can satisfy it.  The environment has a strategy to force a violation regardless of controller choices.

\smallskip
\textbf{Causes:}
\begin{itemize}
  \item Contradictory requirements (e.g., be in two mutually exclusive states).
  \item Impossible state combinations given the system topology.
  \item The environment can force the system into a violating state.
  \item Over-constrained controllable actions.
\end{itemize}
\end{cheatbox}

\begin{cheatbox}{Diagnostics Block}
Enable diagnostics in \code{.ctxdsl} to get detailed feedback:
\begin{lstlisting}[style=ctxdsl]
controllers {
    controller Ctrl {
        source = Plant;
        satisfying = Spec;
        diagnostics {
            counterexample = true;
            deadlock_traces = true;
            max_counter_traces = 100;
            proof_obligations = false;
        }
    }
}
\end{lstlisting}

\smallskip
\begin{tabularx}{\linewidth}{@{}lX@{}}
\toprule
\textbf{Option} & \textbf{Purpose} \\
\midrule
\code{counterexample} & Generate a violating trace \\
\code{deadlock\_traces} & Show traces leading to deadlocks \\
\code{max\_counter\_traces} & Cap the number of traces \\
\code{proof\_obligations} & Show intermediate obligations \\
\bottomrule
\end{tabularx}
\end{cheatbox}

%% ---- COLUMN 2 ----

\begin{cheatbox}{CLI Flags}
Override diagnostics from the command line:
\begin{lstlisting}[style=shell]
mununu context synth file.ctxdsl \
    --formula Spec \
    --automaton Plant \
    --counterexample \
    --deadlock-traces \
    --max-counter-traces 50 \
    --no-proof-obligations \
    --dump-diagnostics diag.json
\end{lstlisting}

\smallskip
\begin{tabularx}{\linewidth}{@{}lX@{}}
\toprule
\textbf{Flag} & \textbf{Effect} \\
\midrule
\code{-{}-counterexample} & Enable counterexample trace \\
\code{-{}-deadlock-traces} & Enable deadlock trace output \\
\code{-{}-max-counter-traces N} & Limit number of traces \\
\code{-{}-no-proof-obligations} & Suppress proof obligations \\
\code{-{}-dump-diagnostics F} & Write diagnostics to file \\
\bottomrule
\end{tabularx}
\end{cheatbox}

\begin{cheatbox}{Diagnostic Output}
When synthesis fails, diagnostics report:
\begin{enumerate}[leftmargin=*]
  \item \textbf{Violating initials} --- initial states outside the winning region.
  \item \textbf{Counterexample trace} --- a sequence of transitions leading to violation.
  \item \textbf{Counterstrategy traces} --- environment moves that defeat any controller.
  \item \textbf{Proof obligations} --- sub-formulas that failed at each fixpoint iteration.
\end{enumerate}
\end{cheatbox}

\begin{tipbox}{Debugging Unrealizable Specs}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Check violating initials} --- which starting states are outside the winning set?
  \item \textbf{Read the counterexample trace} --- follow the sequence of labels to understand the violation path.
  \item \textbf{Look for contradictions} --- are two requirements mutually exclusive?
  \item \textbf{Compare with a known-realizable formula} --- start from a simpler spec that works and add requirements incrementally.
  \item \textbf{Check controllability} --- can the controller actually prevent the bad transitions?
  \item \textbf{Simplify the environment} --- restrict non-determinism to isolate the conflict.
\end{enumerate}
\end{tipbox}

\begin{warnbox}{Common Causes}
\begin{itemize}
  \item \textbf{Mutually exclusive states} --- e.g., requiring \code{Open \&\& Closed} simultaneously.
  \item \textbf{No guaranteed transitions} --- requiring progress but the environment controls all relevant labels.
  \item \textbf{Over-constraining the controller} --- leaving no valid moves in certain states.
  \item \textbf{Liveness without fairness} --- expecting ``always eventually'' without environment cooperation.
  \item \textbf{Topology mismatch} --- the composition does not connect states the spec assumes are reachable.
\end{itemize}
\end{warnbox}

\begin{tipbox}{Lasso Traces}
Liveness counterexamples use lasso format:
\code{prefix -> (cycle)\^{}$\omega$}

Example: \code{Red -> (PedWaiting)\^{}$\omega$}

Use \code{-{}-counterexample} with synthesis to see lasso traces.
\end{tipbox}

\begin{cheatbox}{Advanced CLI Flags}
\code{-{}-extract-strategy} --- positional strategy (one ctrl transition per state)
\code{-{}-counterstrategy} --- graph env winning region (with \code{context graph})
\end{cheatbox}
