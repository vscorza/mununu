# EXP-0007: BindingStack — replace per-iteration HashMap<FormulaVarId, BitVec> clone
# in eval_fixpoint with an enter-on-entry / restore-on-exit pattern that mutates
# `bindings` in place.
#
# Source change in crates/mununu-core/src/mu_calculus/evaluator.rs:
#   - 8 method signatures: bindings: &HashMap<...> → &mut HashMap<...>
#       (eval_node, bitwise_and, bitwise_or, eval_modal, eval_fixpoint,
#        variable_bits, eval_node_tri, eval_fixpoint_tri)
#   - 4 top-level call sites switched from `let bindings = HashMap::new(); &bindings`
#       to `let mut bindings = ...; &mut bindings`
#   - eval_fixpoint split into outer (binding scope) + eval_fixpoint_in_scope (inner loop)
#   - Same pattern applied to eval_fixpoint_tri
#
# Per-iteration cost:
#   OLD: bindings.clone() (deep-clones K BitVecs) + 1 BitVec clone for var insert
#   NEW: 1 BitVec clone for bindings.insert(var, ...)
#
# Per-call overhead added:
#   NEW: 1 bindings.remove(&var) at entry + 1 bindings.insert/remove at exit
#
