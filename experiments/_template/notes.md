# Free-form observations for EXP-NNNN

Use this file for everything that doesn't fit the structured `log.md`:

- Surprising profiler output ("perf record" / `samply` flame graphs).
- Conversations or design discussions worth preserving.
- Architectural alternatives considered and why we didn't pick them.
- Random hypotheses to test in followup experiments.
- Verbose error output, panics, or compilation issues encountered.

Append-only. Date entries with `## YYYY-MM-DD` headers. Do not delete — append "REVISED" / "WITHDRAWN" notes instead.
